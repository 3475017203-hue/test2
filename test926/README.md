# 上商淘 · 上海商学院校园二手交易平台

> 上海商学院专属校园闲置二手交易平台 —— 黑客松演示项目（前端 H5 + Node.js 后端 + MySQL）

## 📖 项目简介

「上商淘」是面向上海商学院在校学生的二手交易平台，支持**商品发布 → 审核员审核 → 上架 → 浏览购买 → 交易完成**的完整闭环，并提供社交发现、即时聊天、通知中心等功能。

- **定位**：校园内 C2C 二手交易
- **双角色**：普通用户（发布 / 购买）+ 审核员（审核商品）
- **前端**：单文件 HTML + CSS + JavaScript（零依赖，无需构建）
- **后端**：Node.js + Express + MySQL（JWT 鉴权）
- **适配**：桌面端预览（390×844 手机框）/ 移动端全屏自适应

## 🎯 核心功能

### 1. 登录 / 注册
- 手机号 + 验证码登录（演示验证码：`1234`）
- **新用户注册**：登录页「新用户注册」→ 自定义昵称 + 手机号 + 验证码，注册即自动登录；注册信息本地持久保存，再次登录自动恢复昵称
- 登录页身份选择（普通用户 / 审核员）
- 第三方登录入口（微信/QQ/校园卡）

### 2. 首页
- 品牌头部（标题渐变文字 + 居中副标题）+ 通知铃铛（未读角标）
- 搜索框（标题 / 描述实时过滤）
- 轮播 Banner、5 大分类入口
- 排序 Tab（全部 / 最新 / 附近 / 价格）+ 商品数量统计
- 双列商品瀑布流，新商品带「新上架」标签

### 3. 发布商品
- **本地上传图片**（最多 9 张，FileReader 预览）
- 商品名称（30 字限制 + 字数统计）
- 8 大分类、价格、交易选项、描述、联系方式
- 提交后进入**待审核**状态，首页暂不显示

### 4. 审核工作台（审核员专属，紫色主题）
- **独立工作台首页**：紫色渐变 Hero 头图 + 日期问候 + 官方认证标识，与普通用户蓝色主题明确区分
- **数据概览**：待审核 / 今日已处理 / 已上架 / 已驳回（数字滚动动画），点击直达对应队列
- **快捷入口**：待审核、已通过、已驳回、发布闲置
- **最新待审核**：商品 mini 卡片，可直接「通过 / 驳回」
- **审核动态**：最近审核操作时间线
- **右上角操作**：铃铛通知（未读角标）+ 设置面板（账号设置 / 发布闲置 / 切换身份 / 退出登录）
- 审核队列页保留三标签（待审 / 已通过 / 已驳回），结果自动写入通知推送给发布者

### 5. 我的订单
- 五个标签：全部 / 待发货 / 待收货 / 已完成 / 已取消
- **下单自动生成订单**（含订单号、商品快照、默认收货地址、下单时间）
- 模拟卖家 2.5 秒内自动发货；支持「查看物流」「提醒发货」
- 「确认收货」后触发五星 + 文字评价
- 「取消订单」商品自动重新上架；已取消订单可删除 / 再次购买
- 点击订单卡片查看**订单详情**（收货信息 + 下单→发货→收货进度时间线）

### 6. 发现（社交帖子流）
- 帖子卡片：作者头像 + 身份标签 + 时间校区 + 正文 + 多图网格
- 多图布局 1/2/3/4 张自适应，点击**查看大图**（全屏图片查看器）
- 点赞 / 评论（评论面板含真实评论列表与输入发送）/ 分享（多渠道分享面板）
- 帖子「更多」：收藏、复制链接、免打扰、不感兴趣、举报；分类筛选 + 排序 + 实时搜索

### 7. 通知中心
- 类型：审核通过 ✅ / 审核驳回 ❌ / 订单消息 🛒 / 收藏与系统通知 🔔
- 铃铛未读角标实时更新
- 通知面板支持单条已读 / 全部已读

### 8. 消息
- 会话列表（头像、预览、未读角标、交易中标签）
- 聊天详情页（气泡对话、发送消息、自动回复）
- 消息设置：通知、隐私、清空聊天记录

### 9. 我的 / 设置（所有按钮全部可用，无任何空白占位）

- 我的服务：我的发布（下架/重新上架/撤回/驳回原因/重新发布）、我的收藏、我的订单、浏览记录

- 消息通知设置、隐私设置（在线状态、陌生人私信、清缓存、第三方清单、注销入口）
- 帮助与反馈：5 条常见问题手风琴 + 分类反馈表单；版本信息与更新日志

## 🔄 完整交易流程（现场演示脚本）

```
普通用户发布商品 → 切换审核员（紫色工作台）→ 审核通过 → 切回普通用户 → 商品已上架
→ 立即购买 → 确认下单（生成订单）→ 卖家自动发货 → 确认收货 → 五星评价
```

| 步骤 | 操作角色 | 说明 |
|------|---------|------|
| 1. 发布 | 普通用户 | 上传图片 + 填写信息 → 提交，商品状态 `pending`，首页不可见 |
| 2. 审核 | 审核员 | 工作台「最新待审核」点「通过」（或「驳回」），操作写入审核动态 |
| 3. 上架 | — | 状态变 `online`，发布者收到通过通知，商品出现在首页并带「新上架」 |
| 4. 购买 | 普通用户 | 商品详情 → 立即购买 → 订单确认弹窗 → 确认下单，自动生成订单 |
| 5. 发货 | — | 2.5 秒后订单自动变「待收货」，首页商品数减一，收到发货通知 |
| 6. 完成 | 普通用户 | 我的订单 → 确认收货 → 五星 + 文字评价，订单状态 `done` |

> 驳回路径：审核员点「驳回」→ 商品状态 `rejected`，发布者收到带原因的通知；可在「我的发布」查看原因并一键带入信息重新发布。
>
> 取消路径：待发货状态可取消订单，商品自动重新上架、回到首页可被再次购买。

## � 后端部署

### 技术选型
**Node.js + Express + MySQL 8.0**，使用 JWT 做登录鉴权、Multer 处理图片上传、bcrypt 加密密码。选 Node.js 是因为它轻量、与前端同语言、启动快，非常适合黑客松快速交付。

### 1. 导入数据库

```bash
# 确保已安装 MySQL 8.0 并启动
mysql -u root -p < server/schema.sql
```

该脚本会创建 `shangtao` 数据库及 8 张表，并写入一个普通用户和一个审核员。

> **Windows 中文乱码/ERROR 1067 注意**：脚本开头已含 `SET NAMES utf8mb4`，可直接在 mysql 客户端内 `SOURCE d:/test/server/schema.sql`。若仍遇到 `Invalid default value for ...`，请用 `mysql -u root -p --default-character-set=utf8mb4` 启动客户端再执行。脚本含 `DROP TABLE IF EXISTS`，可安全重复执行。

### 2. 配置数据库连接

默认连接配置见 [server.js](server/server.js)，可通过环境变量覆盖：

```bash
set DB_HOST=localhost
set DB_PORT=3306
set DB_USER=root
set DB_PASSWORD=你的密码
set DB_NAME=shangtao
set JWT_SECRET=自定义密钥
set PORT=3000
```

### 3. 安装依赖并启动

```bash
cd server
npm install
npm start
```

看到以下输出即成功：

```
=================================
  上商淘后端服务已启动
  地址: http://localhost:3000
  （同端口托管前端页面）
=================================
```

健康检查：[http://localhost:3000/api/health](http://localhost:3000/api/health)。

## 🗄️ 数据库设计

数据库名 `shangtao`，共 8 张表，字符集 `utf8mb4`：

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `user` | 用户（含角色） | phone、role(0普通/1审核员)、credit_score |
| `product` | 商品 | seller_id、status(0待审/1上架/2驳回/3已售)、reject_reason、auditor_id |
| `product_image` | 商品多图 | product_id、image_url |
| `order` | 订单 | order_no、buyer_id、seller_id、status |
| `notification` | 通知 | user_id、type、is_read |
| `favorite` | 收藏 | user_id、product_id |
| `post` | 社区帖子 | user_id、content、like_count |
| `post_image` | 帖子图片 | post_id、image_url |

> 商品审核状态以 `product.status` 为唯一数据源，审核记录通过 `auditor_id / audit_time` 体现，避免多状态字段不一致。

## 📱 移动端适配与体验

- 使用 `100svh` / `100dvh` 动态视口高度，解决浏览器地址栏挤压问题
- 底部导航栏 `position: fixed` + `safe-area-inset` 安全区适配，始终可见
- 隐藏移动端重复状态栏，触摸去除高亮：`-webkit-tap-highlight-color: transparent`

### 返回导航（全页面可回退）
- **页面历史栈**：所有页面跳转自动入栈，各页面返回键一键回到上一页（而非固定回首页）
- **物理返回键**：手机/浏览器返回键逐层关闭浮层（详情 → 大图 → 通知 → 弹层 → 子页面）；浮层历史记录支持自动消费（自愈），不会出现"按返回没反应"
- 登录 / 退出登录自动重置导航栈，审核员从工作台进入的页面返回时正确回到工作台

### 数据持久化
- **商品图片落盘**：发布页选图后自动上传到后端 `POST /api/upload`，图片文件持久保存在 `server/uploads/`，商品引用 `/uploads/xxx` URL，重启 / 刷新后图片依然可访问
- **业务数据本地持久化**：商品、订单、收藏、浏览记录、通知、个人资料、收货地址、评论、审核动态自动存入 `localStorage`（3 秒定时 + 关页前 + 关键操作后三重保障），刷新页面全部恢复
- 容量超限自动降级：剥离 base64 图片仅存引用，保证存储不崩溃；纯静态模式（8000 端口）无后端时自动退回 base64 预览，不影响发布流程

### 高级感细节
- **毛玻璃头部**：首页 / 审核队列 / 发布页 / 子页面 header 半透明 + `backdrop-filter` 磨砂
- **首屏骨架屏**：商品加载前显示微光骨架卡片，避免白屏生硬
- **交错入场动画**：商品瀑布流 / 订单 / 审核列表 / 帖子流依次浮现
- **页面切换过渡**：切页淡入上浮动画；卡片按压缩放反馈
- **数字滚动**：工作台概览数字从 0 弹性滚动到目标值
- **Toast 升级**：毛玻璃胶囊造型 + 弹性缩放动画

## 📝 使用教程（现场演示）

1. 打开 [http://localhost:3000/](http://localhost:3000/)，选择「普通用户」，验证码输入 `1234`，登录
2. 点底部「+」发布一件商品（上传图片、填名称价格），提示「等待审核员审核」，首页暂不显示
3. 到「我的」页点「⇄ 切换身份」切为审核员，进入紫色审核工作台
4. 在「最新待审核」点「通过」（或「驳回」），审核动态同步更新
5. 切回普通用户，可见商品已出现在首页并带「新上架」标签，铃铛有通知角标
6. 点开商品 → 立即购买 → 确认下单，自动生成订单；2.5 秒后收到发货通知
7. 「我的订单」中确认收货 → 五星评价，交易完成
